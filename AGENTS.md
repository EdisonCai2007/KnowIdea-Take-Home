## Repo Guidance

- Do not add new tests, expand test coverage, or prioritize test work unless the user explicitly asks for it.
- Do not treat `pytest` or other automated test runs as a routine completion step for ordinary feature work in this repo.
- Prefer manual smoke validation for runtime behavior unless the user specifically requests automated test changes or execution.
- Do NOT run tests after new features are implemented. Tests are only for manual use, and shouldn't be automated by Codex
